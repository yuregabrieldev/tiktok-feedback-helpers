# Mood — abrir no Codex

Esta é a cópia editável mais recente da versão de apresentação do Mood, exportada em 12 de novembro de 2026. Contém TanStack Start, React, TypeScript, Tailwind, componentes, fontes, fotografias, vídeo de stock, dados demonstrativos e favicon com fundo transparente. A direção visual é a Proposta B.

## Como abrir
1. Extraia o ZIP e abra a pasta mood no Codex.
2. Instale Node.js 24.22.1 e Bun 1.4.4. No terminal da pasta, execute `bun install --frozen-lockfile` e depois `bun run dev`.
3. Testes: `bun run typecheck`, `bun run lint`, `bun run test`, `bun run build`.
