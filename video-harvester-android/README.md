# Simples Scraper (antigo Video Harvester)

Este projeto Android é o **Simples Scraper**, um scanner/crawler independente para identificar vídeos e fontes em páginas web.

**Não é o Harvester Browser.** Ambos partilham o repositório GitHub, mas mantêm APKs, branches e histórico de releases próprios.

- **Simples Scraper**: branch `video-harvester-android` (nome técnico legado), código nesta pasta, `applicationId=com.yure.videoharvester`; releases `simples-scraper-v...`.
- **Harvester Browser**: branch `harvester-browser-v27-ptbr-metadata`, scripts em `harvester-browser/v2.7.0/`; releases `harvester-browser-v...`. O código fonte completo do Browser é reconstruído por workflow próprio.

O identificador Android de Simples Scraper permanece o mesmo para permitir atualização sobre a instalação anterior e preservar os dados do utilizador. O nome exibido passa a ser **Simples Scraper**.

O motor BR experimental é opcional, pode ser desligado e não executa extensões CloudStream .cs3 nem contorna DRM, anúncios obrigatórios ou controlos de acesso.

O APK instalável é publicado nas [Releases do GitHub](https://github.com/yuregabrieldev/tiktok-feedback-helpers/releases).
